# Bezpieczeństwo publikacji

Repozytorium zawiera dokumentację Odoo, a nie działającą aplikację. Jeśli znajdziesz w nim przypadkowo opublikowane dane osobowe, sekrety, hasła, tokeny, konfigurację klienta albo potencjalnie niebezpieczną instrukcję, nie zakładaj publicznego zgłoszenia z tymi danymi.

Wyślij krótką wiadomość na contact@sysmo.pl, z tematem „GitHub Odoo playbook: bezpieczeństwo”. Podaj nazwę pliku i opis problemu bez dołączania wrażliwych danych, jeśli nie są konieczne. Nie wysyłaj prawdziwych sekretów zwykłą pocztą e-mail.

Bezpieczeństwo konkretnych wdrożeń i sposób raportowania podatności ich oprogramowania ustala się osobno w projekcie.
