# Przykłady projektów Odoo ERP

Scenariusze do warsztatów i szkoleń zespołu. Są syntetyczne: firmy, liczby i dokumenty wymyśliliśmy na potrzeby ćwiczeń, to nie są opisy projektów ani wyniki klientów Sysmo.

| Przykład | Temat do przećwiczenia |
|---|---|
| [Hurtownia B2B](hurtownia-b2b.md) | Discovery, FIT/GAP, integracje, migracja i UAT end-to-end |
| [Sklep: utracona odpowiedź API](sklep-zamowienia-timeout.md) | Idempotencja, retry, duplikacja i raport uzgodnienia |
| [Produkcja: zmiana BOM](produkcja-bom-zmiana.md) | Kontrola wersji produkcji i uruchomionych zleceń |
| Usługi: ewidencja czasu i faktura *(wkrótce)* | Akceptacja godzin, korekty i dostęp wielospółkowy |
| Multi-company: uprawnienia *(wkrótce)* | Dostęp do spółek, raportów, załączników i API |
| [Migracja otwartych zamówień](migracja-otwarte-zamowienia.md) | Częściowe dostawy i zapobieganie podwójnym wydaniom |

Najlepiej wziąć przykład najbliższy branży klienta i poprosić key userów, żeby opisali własne wyjątki. Różnice zapisujemy w [karcie procesu](../szablony/karta-procesu.md), testy w scenariuszu UAT *(wkrótce)*, a decyzje w [ADR](../szablony/adr-decyzja-architektoniczna.md). Dane rzeczywiste przechowuj wyłącznie w prywatnym systemie.
