# Szablony dokumentów wdrożenia Odoo ERP

**Uwaga:** to publiczne, puste formularze do skopiowania do prywatnego narzędzia projektu. Nie publikuj wypełnionych kart z danymi, logami, nazwami systemów klientów ani sekretami.

| Szablon | Kiedy użyć | Kto zatwierdza |
|---|---|---|
| [Karta projektu](karta-projektu.md) | Kwalifikacja i kick-off | Sponsor / PM |
| [Notatka discovery](notatka-discovery.md) | Po każdym warsztacie | Właściciel procesu |
| [Karta procesu](karta-procesu.md) | Przed FIT/GAP | Właściciel procesu |
| [Rejestr wymagań](rejestr-wymagan.md) | Przed zamrożeniem zakresu | Właściciel biznesowy |
| Macierz ról *(wkrótce)* | Architektura i testy bezpieczeństwa | Właściciel + security |
| Karta integracji API *(wkrótce)* | Przed pracami integracyjnymi | Biznes + integrator |
| Karta incydentu integracji *(wkrótce)* | Po błędzie / podczas diagnozy API | Integrator + właściciel procesu |
| Plan migracji *(wkrótce)* | Przed dry-run i cutover | Właściciel danych |
| Karta zmiany modułu Python *(wkrótce)* | Przed custom developmentem | Biznes + tech lead |
| ADR: decyzja architektoniczna *(wkrótce)* | Po wyborze wariantu rozwiązania | Decydent + tech lead |
| Karta audytu Odoo *(wkrótce)* | Przed przejęciem utrzymania lub upgrade | Właściciel audytu |
| Scenariusz UAT *(wkrótce)* | Przed testami akceptacyjnymi | Key user / właściciel |
| Checklista Go-Live *(wkrótce)* | Przed produkcją | Sponsor + tech lead |
| [Rejestr ryzyk/decyzji](rejestr-ryzyk-decyzji.md) | Od pierwszego dnia | PM i właściwy decydent |

Pytania do warsztatów są w [rozdziale 03](../docs/03-pytania-do-klienta.md).
